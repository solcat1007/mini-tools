### JSON 格式化工具 JSON 格式化、压缩、校验、排序工具。 **主要功能** - 格式化：美化 JSON 输出，可选缩进级别 - 压缩：去除空格和换行，生成紧凑 JSON - 校验：检查 JSON 格式是否合法，显示顶层类型和键数量 - 转义/反转义：将文本转为 JSON 字符串字面量或还原 - 排序键：按字母顺序递归排列对象键 **快捷键** | 快捷键 | 功能 | |--------|------| | Ctrl+Enter | 格式化 | | Ctrl+K | 压缩 | | Ctrl+L | 清空 | | Ctrl+Shift+S | 按字母排序键 | **注意事项** - 如果 JSON 解析失败，错误信息会显示在结果区域 - 拖拽 .json 文件到编辑区可直接导入
