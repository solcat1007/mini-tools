### Markdown 编辑器 实时预览的 Markdown 编辑器，左右分栏设计。 **主要功能** - 左侧编写 Markdown，右侧实时渲染预览 - 支持标题、加粗、斜体、代码块、表格、引用等常用语法 - 工具栏快捷插入：加粗/斜体/删除线/代码/标题/引用/列表/链接 - 右键菜单快速操作 - 实时统计字数、行数、字符数 - 导出 .md 和 .html 文件 **快捷键** | 快捷键 | 功能 | |--------|------| | Ctrl+S | 导出 .md 文件 | | Ctrl+Shift+E | 导出 .html 文件 | | Ctrl+O | 打开文件 | | Ctrl+B | 加粗 | | Ctrl+I | 斜体 | **注意事项** - 代码块使用三个反引号包裹，支持语言标注 - 拖拽 .md/.txt 文件到编辑区可直接导入
