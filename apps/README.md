# Mini Tools — 工具详细说明

## 1. Markdown 编辑器 (`markdown-editor.html`)

实时预览 Markdown 编辑器，左右分栏设计。

| 功能 | 说明 |
|------|------|
| 实时预览 | 左侧编写，右侧即时渲染 |
| 语法支持 | 标题、加粗/斜体、删除线、代码块、表格、引用、列表、链接、图片 |
| 导出 | 导出 .md 和 .html 文件 |
| 字数统计 | 实时显示字数、行数、字符数 |

| 快捷键 | 功能 |
|--------|------|
| Ctrl+S | 导出 .md 文件 |
| Ctrl+Shift+E | 导出 .html 文件 |
| Ctrl+O | 打开文件 |
| Ctrl+B | 加粗 |
| Ctrl+I | 斜体 |

## 技术说明

- 纯原生 HTML/CSS/JS，零外部依赖
- 单文件设计，双击即用
- 白色极简主题，白底黑字黑边框
- 每个工具页面顶部有可折叠使用说明
- 所有界面文字为中文
