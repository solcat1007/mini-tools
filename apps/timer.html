### 计时器 多功能计时器，支持倒计时、秒表、番茄钟三种模式。 **主要功能** - 倒计时：设置时/分/秒，支持 1~60 分钟预设 - 秒表：从 0 开始正向计时 - 番茄钟：多阶段序列计时，可自定义添加/移除阶段 - 进度条显示剩余时间比例 - 最后10秒警告色提示 - 浏览器桌面通知 + Web Audio 提示音 - 全屏模式 **快捷键** | 快捷键 | 功能 | |--------|------| | Space | 开始 / 暂停 | | R | 重置 | | ← / → | 切换模式 | | F | 全屏 | **注意事项** - 定时器在后台标签页中可能降速，建议保持页面可见
