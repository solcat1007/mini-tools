# Mini Tools — 轻量级 HTML 实用工具箱

> 纯原生 HTML/CSS/JS 浏览器端工具集，零外部依赖，打开即用。
> 29 个工具覆盖日常开发高频需求：编解码 / 颜色 / 正则 / 哈希 / 二维码 / 密码生成 / Emoji / 进制转换等。

## 快速开始

1. 下载 `index.html` 在浏览器打开，即可使用所有内置工具
2. 或直接打开 `apps/` 目录下的单个工具 HTML 文件
3. 无需安装任何依赖，零配置，零构建

## 工具列表

### 文本处理
- **Markdown 编辑器** — 左右分屏实时预览，支持 GFM 语法 + 代码高亮 + 一键导出 HTML
- **JSON 格式化工具** — 格式化/压缩/校验/转义，语法高亮树形折叠，错误定位一键修复
- **Base64 编解码** — 文本/图片双向转换，UTF-8 中文支持，URL 安全编码
- **HTML 实体编解码** — 特殊字符 ↔ 实体名称/编号双向转换
- **URL 编解码** — 完整 URL / 组件编码，中文 ↔ 百分号编码
- **Unicode 查询** — 字符码点互查，UTF-8/UTF-16 编码字节显示
- **命名风格转换** — camelCase / PascalCase / snake_case 等七种风格互转
- **文本排序去重** — 升序/降序/随机/去重，忽略大小写，行号显示
- **文本统计** — 中英文计数/字节统计/阅读时间估算，实时统计

### 数据与代码
- **正则测试器** — 实时匹配高亮，捕获组显示，替换模式，内置常用正则库
- **哈希计算器** — MD5/SHA-1/SHA-256/384/512，文件哈希，HMAC 带密钥
- **进制转换** — 二/八/十/十六进制互转，浮点数/大整数支持，位运算辅助
- **文本差异对比** — 行级/词级 diff，并排 + 统一双视图，中文友好

### 颜色与 CSS
- **颜色拾取器** — HEX/RGB/HSL/HSV 实时转换，收藏色板，取色器模式
- **颜色格式转换** — HEX/RGB/HSL/HSV/CMYK 五向互转，调色板预览
- **CSS 渐变生成器** — 线性/径向渐变可视化编辑，12 组预设模板
- **CSS 阴影生成器** — box-shadow 多层叠加编辑，text-shadow 支持

### 生成与实用
- **二维码生成器** — 文本/URL/名片/WiFi，自定义颜色 Logo，PNG/SVG 导出
- **UUID 生成器** — UUID v4 批量生成，无连字符格式，随机字符串
- **密码生成器** — 高度可定制密码，强度/熵值评估，批量生成
- **Lorem Ipsum 生成器** — 段落/句子/单词三种模式，一键复制
- **表格生成器** — 可视化行列编辑，合并单元格，导出 HTML/Markdown

### 图像与工具
- **图片压缩** — 质量滑块调节，实时预览对比，Canvas 前端处理
- **截图笔记** — 粘贴截图并标注画笔，选区裁剪，PNG 下载
- **Emoji 查找** — 分类浏览 + 关键词搜索，点击复制，Unicode 码点显示
- **摩斯电码** — 文字 ↔ 摩斯码互转，音频播放，闪灯模拟

### 计时与转换
- **正计时/倒计时** — 倒计时/秒表/番茄钟三合一，圈次记录
- **秒表** — 毫秒精度，Lap 圈次，Space 键启停
- **罗马数字转换** — 数字 ↔ 罗马数字双向转换，语法校验，批处理

## 项目结构

```
mini-tools/
  index.html          # 工具箱总入口（含 Markdown/JSON/Color/Timer 内置工具）
  README.md           # 本文件
  apps/
    README.md         # 详细开发说明和快捷键汇总
    *.html            # 29 个独立工具，每个可单独运行
```

## 技术栈

- **纯原生 HTML/CSS/JavaScript**：无任何外部依赖
- **零构建步骤**：无需 npm、webpack、vite，打开即用
- **白色极简主题**：统一 UI 风格，黑色边框 + 白色底色
- **完全离线可用**：所有逻辑在浏览器端执行，无后端请求
